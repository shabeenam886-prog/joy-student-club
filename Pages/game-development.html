🎮 Game Development Workshops

📖 About the Workshop

Students learn the basics of game development and create simple interactive games using programming concepts.

📚 Topics Covered

  • 🎨 Game Design Basics
  • 💻 Game Programming
  • 🧑‍🎨 Characters and Animation
  • 🗺️ Game Levels and Gameplay
  • 🐞 Testing and Debugging

🛠️ Workshop Activities

Students work on small game projects and learn how to develop, test and improve their games.
